MODUNOTE SUPPORT

使用支援

從建立第一頁到匯出整本 PDF，這裡整理 ModuNote 第一版最常使用的操作。

開始使用

建立自己的筆記方式

1. 建立筆記本與頁面

在「我的筆記」新增筆記本。進入筆記後，可從頁面底部加入空白頁或插入單頁模板；免費版可建立 1 本筆記本，每本最多 10 頁。

2. 手寫與手指模式

選擇筆工具後可調整筆型、顏色與粗細。要操作文字、表格、PDF 或小工具時，先切換到手指圖示；切換模式不會刪除既有手寫內容。

3. 文字方塊

從新增選單插入文字，切到手指模式後點選文字方塊即可使用鍵盤輸入。選取後可移動、調整大小或刪除。

4. PDF 匯入與註解

匯入 PDF 後，可把頁面當成可移動元素，或設為整頁背景，再直接於上方手寫。大型 PDF 需要一些處理時間，完成前請不要重複匯入。

5. 可計算表格

插入表格後切換到手指模式，點選儲存格使用鍵盤輸入。可設定欄位公式、套用到計算欄，以及將最後一列設為加總列。

6. 互動小工具

可加入勾選、計數器、動作按鈕與進度條。小工具可移動、調整大小與編輯，讓同一頁配合清單、追蹤或日常記錄使用。

重複使用與保存

把做好的頁面留下來

單頁模板

完成頁面後，從頁面選單選擇「儲存為我的模板」。之後可在其他筆記中選擇「插入頁面模板」，再繼續修改內容。

匯出 PDF

可匯出目前頁面或整本筆記。匯出的檔案是靜態 PDF，會保留當下可見內容，但勾選、按鈕與公式不會在 PDF 閱讀器中繼續互動。

備份與還原

請定期從 App 內建立備份，並將備份檔存放到你信任的位置。還原前請確認選擇的是 ModuNote 建立的完整備份檔。

回復購買

若曾使用相同 Apple 帳號購買 ModuNote Pro，可在購買頁選擇「回復購買」。付款與購買權益由 Apple 的 App Store 處理。

系統分享

接收結果也取決於目的 App

ModuNote 會把匯出的 PDF 交給 iOS／iPadOS 系統分享介面。Mail、AirDrop 或其他 App 是否能接收，仍會受到接收 App 的分享擴充功能、版本與裝置狀態影響。若某個 App 無法接收，可先儲存到「檔案」，再從該 App 內選取 PDF。

ENGLISH SUPPORT

Core workflows

Use these steps to build, edit, preserve, and share your ModuNote pages.

Handwriting and hand mode

Choose a pen to write and adjust its style, color, and width. Switch to the hand icon before interacting with text, tables, PDFs, or widgets. Existing handwriting remains visible.

Keyboard text

Insert a text box, switch to hand mode, then tap the box to type. A selected text box can be moved, resized, edited, or deleted.

PDF import and annotation

Import a PDF as a movable page element or a full-page background, then add handwriting above it. Allow large files to finish processing before starting another import.

Calculating tables

Switch to hand mode and tap a cell for keyboard entry. Configure column formulas, apply them to a calculation column, or use the final row for totals.

Interactive widgets

Add a checkbox, counter, action button, or progress bar. Move, resize, and edit each widget to fit your page.

Single-page templates

Save the current page as a personal template, insert it into another notebook, and continue editing the new page.

Export a PDF

Export one page or the entire notebook. The result is a static PDF: visible content is preserved, but widgets and calculations are not interactive in a PDF reader.

Backup and restore

Create backups regularly and keep them in a location you trust. Select a complete backup created by ModuNote when restoring.

Restore purchases

If you previously bought ModuNote Pro with the same Apple Account, use Restore Purchases on the purchase screen. Apple manages payment and entitlement records.

Contact support

Include your device model, system version, app version, and reproducible steps. Do not email private notebook content, personal photos, contact details, medical information, or financial information.
